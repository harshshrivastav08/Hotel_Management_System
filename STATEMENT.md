Project Title

Hotel Management System

Project Statement

The main aim of this project is to create a simple Hotel Management System using Python. The system is designed to handle some basic hotel activities in an easy and organized way.

In a hotel, keeping track of guests, rooms, bookings, extra services, and bills can become difficult if everything is done manually. This project provides a small computer-based solution for these tasks.

The system allows the user to:

Add and manage guest details
View and search guest information
Add and manage hotel rooms
Check room availability
Book rooms for guests
Check out guests
Add hotel services such as food or other services
Calculate service charges
Generate the final bill
Store information in JSON files for later use

The project is completely console-based, so no graphical interface or internet connection is required. All the data is stored locally using JSON files.

I divided the project into different Python files so that each part of the system has its own purpose. This also makes the code easier to understand and modify.

Through this project, I wanted to practise basic Python concepts such as functions, loops, conditional statements, dictionaries, lists, file handling, JSON, modules, and date/time operations.

The project is mainly made for learning purposes, but it can also be used as a basic example of how a real-world hotel management system works.
